# Devis Chantier

Application de devis pour le nettoyage de fin de chantier : lecture des dossiers (Word, Excel, PDF, photos), calcul des heures et de l'équipe nécessaire, TVA française automatique, planning et devis PDF.

## Installer sur Android

1. Ouvre **https://masmin2424.github.io/devis-chantier/** dans Chrome.
2. Menu ⋮ → **Installer l'application** (ou **Ajouter à l'écran d'accueil**).
3. L'icône « Devis Chantier » apparaît sur l'écran d'accueil. Après la première ouverture, l'application fonctionne aussi hors connexion.

## Données

Les devis, l'équipe, le matériel et les fichiers sont enregistrés uniquement sur le téléphone. Rien n'est envoyé sur un serveur.
Pour garder une copie ou transmettre ses réglages : **Réglages → Sauvegarde et partage → Exporter**, puis **Importer** sur l'autre appareil.
